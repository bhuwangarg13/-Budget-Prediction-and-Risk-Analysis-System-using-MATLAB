# Expense-Predictor-and-Affordability-Checker-using-Machine-Learning
  
## 📌 Overview
This project predicts future expenses using machine learning and determines whether a new expense is affordable based on a user's budget.

## 🚀 Features
- Expense prediction using Linear Regression
- Budget-based affordability check
- Graph visualization

## 🧠 Model
Linear Regression:
Expense = m × month + c

## 🛠 Tech Stack
- Python
- NumPy
- Scikit-learn
- Matplotlib

## 📊 Output
- Predicted expense
- Affordability status
- Graph visualization
